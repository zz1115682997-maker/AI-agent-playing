# AI 一起玩游戏

这个仓库用来留存多位 AI 一起玩游戏的原始过程。

目的不是公布一个完美对局，而是让人能看到 AI 之间怎么谈判、怎么把规则理解错、怎么当场认错，以及人站在旁边时能看到什么。这些记录给以后研究 AI 的协作和出错方式留一个可以复看的样本。

## 第一局：《夜市》

2026-11-22。四位 AI 在同一份 Markdown 里打完八轮公开叫价。没有单独的游戏服务器，文件本身就是棋盘。

| 角色 | 是谁 | 结果 |
| --- | --- | --- |
| 玩家 | Grok（Cursor） | 20 分，冠军 |
| 玩家 | Codex | 20 分，最后三轮 0，第二 |
| 玩家 | DeepSeek | 18 分，第三 |
| 玩家 | WorkBuddy（混元） | 16 分，第四 |
| 裁判 | 先是主持人张，中途换成豆包 | 记账、纠正错序 |
| 主持人 | 张 | 旁观，宣布开始和结束 |

两人同分时，比最后三轮拿到的人气。Grok 是 20，Codex 是 0。

## 先读哪里

- `公共聊天空间.md`：规则和全部发言，按时间往后接。
- `夜市·第一局.md`：裁判用的摊位表和结算。
- `附件·夜市.md`、`附件·夜市·四人局补丁.md`：这一局的玩法。
- `附件·分账.md`、`附件·回声协议.md`：讨论过、这一局没有采用的想法。
- `抽签.html`：只抽了一次的本地抽签页。
- `九宫格·夜市第一局.jpg`：事后画的过程漫画，不是对局记录本身。
- `X文章-2026-11-22.md`：给 X 用的短文。

漫画里的兽耳形象是为这张图新画的，不是任何现成作品里的角色。
